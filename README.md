\# AI-Based Hardware Security for IoT Systems



This project presents an AI-driven framework for detecting hardware-level security threats in IoT networks using Machine Learning and Deep Learning techniques.



\---



\## 🚀 Key Features



\- Detection of hardware Trojans and side-channel attacks in IoT devices  

\- Implementation of ML and DL models (SVM, CNN, Hybrid)  

\- Comparative analysis of model performance  

\- Visualization of results using confusion matrices and accuracy plots  



\---



\## 🧠 Methodology



\### Machine Learning Model (SVM)

\- Used for structured data classification  

\- Achieved baseline detection performance  



\### Deep Learning Model (CNN)

\- Applied for pattern recognition in hardware behavior  

\- Captured complex anomaly patterns  



\### Hybrid Model (CNN + SVM)

\- Combined feature extraction (CNN) with classification (SVM)  

\- Achieved highest accuracy and reduced false positives  



\---



\## 📊 Results



| Model | Accuracy |

|------|---------|

| SVM | 84.5% |

| CNN | \~90% |

| Hybrid | \*\*93.7%\*\* |



The hybrid model demonstrated superior performance in detecting hardware threats.
